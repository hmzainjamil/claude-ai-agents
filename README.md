# claude-ai-agents

> **210 specialist Claude AI agents** organized by division — the complete agent army powering HMZ AI Agency.

Part of [claude-ai-system](https://github.com/hmzainjamil/claude-ai-system).

---

## Overview

Each agent is a specialized AI persona with domain-specific knowledge, tools, and decision frameworks. Agents activate individually or as a coordinated division.

```
~/.claude/agents/     ← 210 active agents
Activation:  /all-agents          → all 210 fire simultaneously
             /agency-run          → orchestrator loads relevant division
             "Activate [X] mode"  → specific agent personality
```

## Activation Commands

```bash
# All 210 agents simultaneously
/all-agents

# Division orchestrator
/agency-run

# Specific agent personality
"Activate Security Engineer mode"
"Activate PPC Campaign Strategist mode"
"Activate Game Designer mode"

# Auto-routing (keyword detection)
"Review my code for security issues"     → Security Engineer
"Build a Google Ads campaign"            → PPC Campaign Strategist
"Design a level for my game"             → Level Designer
"Audit my Meta ads account"              → Paid Media Auditor + Meta Ads Analyst
```
